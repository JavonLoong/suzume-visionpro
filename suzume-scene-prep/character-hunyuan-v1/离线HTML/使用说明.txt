铃芽之旅 · 离线 HTML

直接用 Chrome 或 Edge 双击打开 HTML，不需要启动 Python、Node 或本地服务器。
每一个 HTML 都内嵌了自身需要的脚本、模型、贴图和几何数据；可单独复制到其他文件夹或电脑。

铃芽之旅_全部场景_离线珍藏.html
  总入口：v49 主视觉、v38 海报庭院、v37 电影开门、v49 正面和斜侧原始渲染。
  其中的“保存双场景 Blender 模型”可导出原始 v38 .blend 文件。
  包含完整资源和 Blender 源文件，文件较大，首次打开需等待资源展开。

铃芽之旅_v49_旋转场景.html
  独立 v49 场景，同时收录该版原始渲染图。

铃芽之旅_v38_海报庭院.html
  独立 v38 海报庭院场景。

铃芽之旅_v37_电影开门.html
  独立 v37 电影开门场景。

铃芽之旅_v49_原始渲染.html
  仅查看和保存 v49 正面、斜侧原图，文件最小。

三维操作：拖动旋转；滚轮缩放；右键或 Shift 拖动平移。
视角下拉框可切换到门前、左侧、右侧、背面、俯瞰、门后草地和人物近景。
按钮可开关门和播放/暂停水波。

这些文件保留所引用的 v49 / v38 / v37 版本，不将它们替换为 v56。
“打包清单.json”和“验证”目录为核验资料，移动 HTML 时不需要一同携带。
